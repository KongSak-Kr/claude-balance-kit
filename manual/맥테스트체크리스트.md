## B. 크롬 확장

| # | 할 일 | 기대 결과 | 아이맥 | 맥북 | 메모 |
|---|---|---|---|---|---|
| B1 | (A 에서 확장을 넣은 뒤) 설정 탭 | 「설치됐어요」 안내 카드가 맨 위에 보임 | | | |
| B2 | 설정에 `sk-ant-admin` 이 아닌 글자 넣고 연결 확인 | "관리자 키 형식이 아닙니다" | | | |
| B3 | 실제 관리자 키 넣고 **연결 확인** | "연결됨 — 키를 저장했습니다. 이번 달 사용액 $…" | | | |
| B4 | B3 의 이번 달 사용액과 콘솔 Cost 화면(platform.claude.com/cost) 비교 | 대략 같음(최대 하루 늦게 반영) | | | |
| B5 | 결제 페이지(settings/billing)를 직접 연 뒤 `$` 아이콘 | 콘솔 화면의 Credit balance 와 같은 금액 | | | |
| B5-1 | (프로모션 크레딧이 있는 계정) `$` 아이콘 | 큰 숫자 위 라벨 「프로모션 크레딧」, 금액이 결제 화면 Promotional credits 표의 Remaining balance 합계(만료 지난 것 제외)와 같음, 아래 「구매한 크레딧 $…」 | | | |
| B5-2 | 같은 창 | 「프로모션 만료 ○년 ○월 ○일」이 표의 가장 빠른 Expires on 과 같음 | | | |
| B5-3 | 설정 1번을 「구매한 크레딧」으로 저장 → 1분 뒤 `$` | 큰 숫자가 Credit balance, 아래에 「프로모션 크레딧 $…」 | | | |
| B6 | 결제 페이지를 닫고 `$` 아이콘 | "잔액 확인 중…" → 탭이 잠깐 열렸다 닫힘 → 진한 글씨 + "방금 확인" (20초 안) | | | |
| B7 | `$` 아이콘을 누르자마자 팝업 밖을 눌러 닫기 → 10초 뒤 다시 열기 | 새 잔액이 저장되어 있음 | | | |
| B8 | 1분 안에 다시 열기 | "1분 안에 이미 확인했습니다" 안내, 탭이 안 열림 | | | |
| B9 | 최근 충전일 | 결제 페이지 Invoice history 의 마지막 Credit grant 날짜와 같음 (출처 "결제 내역") | | | |
| B10 | 사용액 오늘/이번 주/이번 달 | 숫자가 보이고 "○○까지 반영됨" 문구 | | | |
| B11 | 콘솔에서 로그아웃 → `$` 아이콘 | "콘솔 로그인 필요", 잔액 숫자는 회색으로 이전 값 | | | |
| B12 | 다시 로그인 → `$` 아이콘 | 정상 표시로 돌아옴 | | | |
| B13 | 설정에서 알림 기준을 현재 잔액보다 크게(예 : 1000) → 저장 → 1분 뒤 `$` 아이콘 | 아이콘에 빨간 `!`, 맥 알림 "Claude 잔액 부족 알림" 1번 | | | |
| B14 | B13 상태에서 1분 뒤 다시 확인 | 알림이 또 뜨지 않음(배지만 유지) | | | |
| B15 | 기준을 5 로 되돌리고 저장 → 1분 뒤 확인 | `!` 사라짐 | | | |
| B16 | 15분 기다린 뒤 팝업 열기 | 사용액 반영 시각/값이 갱신됨(데이터 지연으로 같을 수도 있음 — 메모) | | | |
| B17 | 크롬 완전히 종료 후 다시 실행 | 개발자 모드 경고 창이 뜨면 닫기 · 확장 계속 동작 | | | |
| B18 | 와이파이 끄고 설정의 연결 확인 | "인터넷 연결을 확인해 주세요" | | | |
