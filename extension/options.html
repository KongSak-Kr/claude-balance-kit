Claude 잔액 키트 설정

설정은 이 컴퓨터의 크롬 안에만 저장됩니다(다른 기기와 동기화하지 않음).

설치됐어요

크롬 오른쪽 위의 $ 아이콘을 누르면 잔액을 바로 볼 수 있어요. 아이콘이 안 보이면 퍼즐 조각 모양 아이콘을 누르고 「Claude 잔액 키트」 옆 핀(압정)을 누르세요.

아래 「관리자 키」는 선택이에요. 오늘 · 이번 주 · 이번 달 사용액과 잔액 부족 알림을 원할 때만 넣으면 돼요. 지금은 이 탭을 그냥 닫아도 괜찮아요.

1. 크게 보여 줄 잔액

고른 잔액이 툴바 버튼의 큰 숫자와 「잔액 부족 알림」 기준이 돼요. 다른 하나는 그 아래 작게 보여요. 프로모션 크레딧이 없으면 구매한 크레딧을 보여 줘요.

2. 관리자 키

사용액(오늘 · 이번 주 · 이번 달)을 가져오는 데 씁니다. 잔액 자체는 결제 페이지에서 읽습니다.

주의 : 관리자 키는 조직 전체를 관리할 수 있는 키입니다. 이 확장은 이 컴퓨터 안에만 저장하며, 확장 폴더를 남에게 주지 마세요.
관리자 키 받는 방법
  1. 조직 관리자(admin) 계정으로 Claude Console 관리자 키 화면을 엽니다.
  2. Create admin key(관리자 키 만들기)를 누르고 이름을 정합니다(예 : 잔액 확장).
  3. 나타난 키를 복사해 위 칸에 붙여 넣고 연결 확인을 누릅니다. 키는 한 번만 보입니다.

개인(Individual) 계정은 관리자 키를 만들 수 없어서 먼저 콘솔의 Organization 화면에서 조직을 설정해야 합니다. 자세한 내용 : 설치안내서 6단계

3. 잔액 부족 알림

$

마지막으로 확인한 잔액(1번에서 고른 것)에서 그 뒤 사용액을 빼서 추정합니다. 추정 잔액이 기준 이하이면 툴바 아이콘에 작은 빨간 ! 표시가 붙고 알림이 한 번 뜹니다. 충전되면 알림이 다시 켜집니다.

4. 사용액 갱신 주기

이 주기마다 비용 조회를 한 번만 하고 바로 쉽니다. 잔액은 툴바 버튼을 눌렀을 때만 확인합니다.

5. 최근 충전일 직접 입력

결제 페이지에서 충전일을 자동으로 못 읽을 때만 넣으세요.
